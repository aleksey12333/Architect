ARCHITECT STUDIO PRO 1.0 — ШПАРГАЛКА ДЛЯ ЖИВОГО ПОКАЗА (DemoKit)
=================================================================

Папка DemoKit лежит рядом с программой (ярлык «Демонстрационный комплект» в меню Пуск).
Цены в прайсе — демонстрационные значения уровня рынка Екатеринбурга, осень 2026.

ПОДГОТОВКА (1 мин)
  Стартовое окно → шаблон «Каркасный корпус» (24 × 18 м, 4 этажа). Уровень опыта — «Инженер-конструктор (ГИП)»:
  включены все модули (Настройки → «Модули и Плагины» → «По уровню опыта»).

1. ДОКАЗАТЕЛЬНАЯ СМЕТА ПО ПРАЙСУ ПОСТАВЩИКОВ (2 мин)
  Файл: Прайс_Екатеринбург_Осень_2026.csv (UTF-8, «;» — открывается и в Excel)
  • Верхний бар → «Ведомость объёмов» → «Загрузить прайс (CSV)» → выбрать файл.
  • «База цен» = «Екатеринбург · осень 2026». В таблице у каждой строки — поставщик
    (УралБетонГрупп, МеталлСервис-Екб, УралСтальКомплект, СтеклоФасад) и документ-основание.
  • Правка цены в ячейке → итог пересчитывается сразу; «Сохранить смету в проект» → .aia.
  Что сказать: каждая сумма прослеживается до прайса и номера документа.

2. КОРПОРАТИВНАЯ БИБЛИОТЕКА КОНСТРУКЦИЙ (2 мин)
  Файл: Стандарт_Девелопера_ЖБИ.aialib.json (12 типоразмеров по ГОСТ/СП)
  • Палитра слева → «Библиотека конструкций ГОСТ и СП» → «Импорт .aialib.json» → выбрать файл.
  • Выделить колонну во вьюпорте → запись «Кд 500×500» → «Назначить выделенным».
  • Выделить стену → «НСд-1» (пирог: керамогранит + минвата 150 + монолит 200) → назначить.
  • Ctrl+Z — ровно один шаг; «Пгд ПГП 80» — ненесущая перегородка (только собственный вес).

3. РЕКОНСТРУКЦИЯ ЗДАНИЯ ПО ПОЭТАЖНОМУ ПЛАНУ (3 мин)
  Файл: План_этажа_секция_А.png (16 × 10 м, 4 окна, 3 двери, зал 10 × 10 м)
  • Капсула ввода внизу → кнопка изображений → «Реконструкция по плану (инженерный конвейер)» → PNG.
  • Масштаб определяется сам (наружная стена 300 мм → 20 мм/пикс); при желании
    калибровка «16000» мм → «Пересобрать». Этажей: 2…5.
  • В сводке: стены 4 + 2, колонны в пролёте 10 м, K_исп ≤ 1,0 (проверено: 0,47…0,75 при 1…5 этажах).
  • «Вставить в сцену» → один шаг Undo; далее — карта напряжений и паспорт расчёта по СП.

4. ФИНАЛ (1 мин)
  • Элемент → «Обоснование по СП…» — паспорт расчёта с формулами и пунктами СП 63/20/22.
  • «‹ Версия N из M ›» в доке → «История изменений»: контрольные точки и сравнение стоимости.
  • F1 — справочный центр.

Если что-то пошло не так: Ctrl+Z / «Отменить всё»; проект не изменяется без подтверждения.
